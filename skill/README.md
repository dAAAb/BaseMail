# Superseded

The published OpenClaw / ClawHub skill lives in its own repository:

- Source: https://clawhub.ai/daaab/skills/basemail
- Registry: https://clawhub.ai/daaab/skills/basemail
- Install: `npx clawhub@latest install basemail` or `openclaw skills install @daaab/basemail`

The files in this folder are the original v0.2 prototype (they call the
deprecated `/api/auth/nonce` + `/api/auth/message` endpoints) and are kept
only for history. Do not use them as a reference for the current API — see
https://basemail.ai/developers and https://api.basemail.ai/api/openapi.json.
